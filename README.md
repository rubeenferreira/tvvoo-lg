# Lista para LG

Playlist de Portugal gerada a partir da instancia publica TvVoo.
Nao e preciso usar Stremio. Continua dependente da disponibilidade do TvVoo e do Vavoo.

O GitHub Actions atualiza diariamente a lista, aproximadamente as 05:23 UTC.
Tambem pode ser executado em Actions > Atualizar lista IPTV > Run workflow.
Falhas na geracao preservam a ultima playlist completa e fazem o workflow falhar.

## Net IPTV

Instala Net IPTV na LG Content Store. Abre e aponta o APP ID.
No portal oficial https://www.netiptv.eu/Upload associa o APP ID ao URL:

https://raw.githubusercontent.com/rubeenferreira/tvvoo-lg/main/tvvoo.m3u

Depois reinicia a app. Testa os canais antes de pagar a ativacao da app.

Nenhuma credencial da antiga conta IPTV e utilizada.
